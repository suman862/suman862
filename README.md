I am an AI/ML Engineer and Applied AI Researcher with a Master's in Applied Artificial Intelligence from Madan Bhandari University of Science and Technology (MBUST), Nepal. My work sits at the intersection of **AI engineering** and **applied AI research**: building modular, production-oriented inference systems while investigating continual learning and visual memory for computer vision.

## Current Research

**Master's Thesis — Continual Panoptic Segmentation with Visual Memory Bank** · MBUST *(in progress)*

I am investigating how visual memory mechanisms can mitigate catastrophic forgetting in incremental panoptic segmentation. The work explores:

- Continual Panoptic Segmentation and incremental learning
- Visual Memory Banks and Visual Prompt Tuning
- The stability–plasticity trade-off in continual learning
- Catastrophic forgetting in dense visual prediction tasks

**Research interests:** Continual Learning · Continual Panoptic Segmentation · Visual Memory Banks · Visual Prompt Tuning · Computer Vision · Multimodal Foundation Models · Large Language Models · Deep Learning

**Generative modeling interests:** Flow Matching · Diffusion Models · World Models
